# Nabta Score

MVP عربي لمنصة تقييم المواقع وصفحات التواصل الاجتماعي بتجربة نظيفة وراقية.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## الموجود حاليًا
- واجهة RTL متجاوبة للجوال والكمبيوتر.
- اكتشاف نوع الرابط: Website / Instagram / Facebook / TikTok / X / YouTube / LinkedIn.
- تقرير بدرجة من 100 مع 5 محاور.
- نقاط قوة وأولويات تحسين.
- API تجريبي محلي يعطي نتائج ثابتة نسبيًا حسب الرابط لعرض تجربة المنتج.

## لتحويله إلى منتج فعلي
استبدل منطق `/app/api/analyze/route.ts` بمحرك تحليل حقيقي. للمواقع: Lighthouse/PageSpeed + فحص SEO/UX/Trust. للسوشال: APIs الرسمية المسموح بها لكل منصة، مع احترام الصلاحيات وشروط الاستخدام. أضف قاعدة بيانات، حسابات مستخدمين، حفظ التقارير، اشتراكات، وتقارير PDF.

> ملاحظة: التصميم مستوحى من مبادئ البساطة والمساحات البيضاء والوضوح، وليس نسخة من واجهات Apple أو علامتها التجارية.
